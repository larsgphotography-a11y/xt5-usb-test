Conservative write test

The app first creates a C1–C7 backup. For the write test it reads one selected slot, writes the same safe mapped values back to that same slot, then reads it again and verifies the result. Unknown properties are never written.

Camera setup

X‑T5 → Network/USB Setting → USB RAW CONV./BACKUP RESTORE. Use a USB‑C data cable and Chrome on Android.
